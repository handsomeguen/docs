# Feature Specification: 집 앞 우체통

**Feature Branch**: `043-mailbox`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "응 나머지 끝날때까지 쭉 진행해줘" (042 다음 마을 순서)

**다루는 명세 요구사항**: TOWN-13 집 앞 우체통(내 우체통은 알림, 다른 집 우체통은 최근 공개 글 3개·집에 들어가기·집 앞으로).

**명세와 다른 점**:
- 친구 마을 구경(TOWN-15)이 아직 없어 [🏘 {닉네임}님의 마을 구경] 버튼은 없다.
- 열린 질문(안 읽은 알림 표시)은 내 우체통 깃발로 답했다: 안 읽은 알림이 있으면 노란 깃발이 위로 선다.
- 우체통 그림은 9×12 도트(45×60px), 집 발밑에서 오른쪽 118px.
- 게임에서 연 우체통 창을 닫으면 초점을 ☰가 아니라 게임에 돌려준다(다음 Space가 메뉴를 열지 않게).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 우체통 (Priority: P1) 🎯

1. 집마다 오른쪽 앞에 우체통. 내 집은 파랑, 다른 집은 빨강. 빈 집터에는 없다.
2. 다가가면 `📬 내 우체통 · Space 소식 보기` / `📬 {닉네임}의 우체통 · Space 소식 보기`. Space·Enter·클릭으로 연다.
3. 내 우체통: `📮 내 우체통`, ☰ 🔔 알림과 같은 최근 알림 5개, [알림함 전체 보기 ›].
4. 다른 집: `📮 {닉네임}님의 우체통`, `{블로그 이름}의 새 글`, 최근 공개 글 3개(✉️ 제목, 최신순, 비공개 없음, 없으면 `아직 공개 글이 없어요.`), [🏠 집에 들어가기] [✨ 집 앞으로]. 방문자도 본다.
