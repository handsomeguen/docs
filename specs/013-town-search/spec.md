# Feature Specification: 마을 검색

**Feature Branch**: `013-town-search`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "계속 진행해줘" (012 다음 순서)

**다루는 명세 요구사항**: BLOG-07 (블로그 안 마을 검색)

**명세와 다른 점**: 검색창은 옆 칸(BLOG-09)의 `🔍 블로그 검색` 바로 아래 `🏘 마을 검색` 상자다. 블로그 줄에는 프로필 사진·캐릭터 얼굴(게임) 없이 `{닉네임} · {블로그 이름}`과 `@주소`만 보인다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 주인이 내 블로그에서 마을의 글·블로그를 찾는다 (Priority: P1) 🎯

**Acceptance Scenarios**:

1. **Given** 내 블로그 홈, **Then** 옆 칸에 `🏘 마을 검색`(칸 안내 `마을의 글·블로그 검색`, 화면 읽기 `검색어`, 최대 50자, [검색])이 있다. 남의 블로그·방문자에게는 없고 `?q=`를 붙여도 보통 블로그 홈이다(검색 쿼리를 돌리지 않는다).
2. **Given** 검색어, **Then** `/@내주소?q=검색어` 왼쪽에 `🔍 '{검색어}' 검색 결과`: 1페이지에만 `블로그`(블로그 이름·닉네임에 검색어, 최대 8곳, 최근 공개 글이 있는 블로그 먼저) + `글 N개`(제목·본문에 검색어가 든 마을 전체 공개 글, 작성자 줄). 비공개 글은 내 글이어도 없다.
3. **Given** 공백만, **Then** `검색어를 적어 주세요`. 찾은 것이 없으면 `검색 결과가 없어요`. 51자 이상은 무시. `%`·`_`·`\`는 글자 그대로. 대소문자 무시.
4. **Given** 글이 9개 이상, **Then** 페이지 번호를 넘겨도 `q`가 남는다. [← 전체 글 보기]로 검색을 벗어난다. 검색 중 카테고리에 고른 항목이 없다.
5. **Given** 375px, **Then** 가로 스크롤 없음.
