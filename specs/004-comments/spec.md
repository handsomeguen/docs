# Feature Specification: 댓글과 답글

**Feature Branch**: `004-comments`

**Created**: 2026-10-11

**Status**: Implemented

**Input**: User description: "계속 진행해줘" (003 다음 순서: 댓글)

**다루는 명세 요구사항**: SOC-01 (댓글 쓰기·삭제), SOC-02 (답글 1단계), POST-05 (목록 카드 `💬 N`)

**이번에 하지 않는 것**: 댓글 보상(GAME-05)과 알림(GAME-08) — 게임·알림이 아직 없다. 캐릭터 그림(게임 없음, 닉네임만). 탈퇴 정리(AUTH-06 없음). 댓글 수정.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 글에 댓글을 쓰고 지운다 (Priority: P1) 🎯

회원이 글 상세 아래 `💬 댓글 N` 영역에서 댓글을 쓰면 목록 맨 아래에 나온다. 작성자·그 글의 블로그 주인·관리자는 [삭제]로 지울 수 있고, 자리에 `삭제된 댓글이에요`가 남는다.

**Acceptance Scenarios**:

1. **Given** 회원, **When** 입력칸(`따뜻한 댓글을 남겨 주세요 💬`)에 쓰고 [댓글 등록], **Then** 새로고침 없이 맨 아래에 나오고(앞뒤 공백 정리) 입력칸이 비워지며 `💬 댓글 N`이 1 는다. 처리 중 버튼은 `등록 중...`이고 눌리지 않는다.
2. **Given** 공백만·1001자, **Then** `댓글을 적어 주세요` / `댓글은 1000자까지예요`, 저장 안 됨, 쓴 내용은 남는다. 입력칸 `maxlength` 1000.
3. **Given** 없는 글·남의 비공개 글로 조작, **Then** `글을 찾을 수 없어요`. 글 ID가 `abc`·`0`·범위 밖이면 `잘못된 요청이에요`.
4. **Given** HTML 태그·주소·줄바꿈, **Then** 글자 그대로, 줄바꿈 유지, 링크 안 됨.
5. **Given** 방문자, **Then** 입력칸 대신 `로그인하면 댓글을 남길 수 있어요`(`로그인` → `/`), [답글]·[삭제] 없음.
6. **Given** 일반 회원, **Then** [삭제]는 자기 댓글에만. 블로그 주인에게는 모든 댓글에. 관리자도 지울 수 있다.
7. **Given** [삭제] → 확인 창 `댓글을 삭제할까요?`에서 [취소], **Then** 그대로. 확인하면 `삭제된 댓글이에요`(흐린 기울임)가 남고 N이 1 줄며 DB 내용은 빈 글자. 지운 내용은 HTML에 없다.
8. **Given** 지울 권한이 없는 댓글·이미 지운 댓글·이상한 ID로 삭제 조작, **Then** 아무것도 바뀌지 않는다 (문구 없음).
9. **Given** 로그인이 풀린 뒤 등록, **Then** `/`로 가고 저장되지 않는다.
10. **Given** 글 목록 카드, **Then** 삭제되지 않은 댓글+답글 수가 `💬 N`으로 보인다 (0이면 숨김).

### User Story 2 - 댓글에 답글을 단다 (Priority: P2)

회원이 삭제되지 않은 원댓글의 [답글]을 눌러 2줄 입력칸(`답글을 남겨 주세요`)에 쓰면 원댓글 아래 들여쓰기로 보인다. 답글에는 [답글]이 없다 (1단계).

**Acceptance Scenarios**:

1. **Given** [답글], **Then** 2줄 입력칸과 [답글 취소] [답글 등록]이 열리고 [답글]은 숨는다. [답글 취소]로 닫고 다시 열면 빈 칸.
2. **Given** 답글 등록, **Then** 원댓글 아래 오래된 순, 왼쪽 선 들여쓰기. 입력칸은 닫히고 [답글]이 다시 보인다. `💬 댓글 N`은 답글도 센다.
3. **Given** 답글 1개 이상인 원댓글을 삭제, **Then** 답글은 그대로, 지운 원댓글에는 [답글]이 없다.
4. **Given** 삭제된 원댓글에 답글 조작, **Then** `삭제된 댓글에는 답글을 달 수 없어요`. 없는 댓글·다른 글의 댓글이면 `답글을 달 댓글이 없어요`. 저장 안 되고 쓴 내용은 남는다.
5. **Given** 답글 삭제, **Then** 댓글과 같은 권한·자리 남김.

### Edge Cases

- 글을 지우면 그 글의 댓글·답글 행이 모두 지워진다.
- 닉네임은 쓸 때가 아니라 지금 프로필 기준이고, 누르면 그 사람 블로그로 간다.
- 375px에서 가로 스크롤 없음, 버튼 높이 44px 이상.

## Requirements *(mandatory)*

- **FR-001**: 내용은 줄바꿈을 `\n`으로 맞추고 앞뒤 공백을 지운 뒤 1~1000자(코드 포인트).
- **FR-002**: 쓰기는 공개 글이거나 내 글일 때만. 글 행을 `FOR KEY SHARE`로 잠그고 확인한다.
- **FR-003**: 삭제는 `deleted_at = now(), content = ''`로 자리를 남긴다. 조건(관리자 OR 작성자 OR 그 글의 블로그 주인)은 UPDATE 문에 넣어 서버가 막는다.
- **FR-004**: 답글은 `replies` 표(`comment_id` → `comments.id`)라 답글의 답글은 구조상 없다. 원댓글은 `FOR SHARE`로 잠근다.
- **FR-005**: 오래된 순(시각 → ID), 페이지 없음. 답글은 원댓글 바로 아래.
- **FR-006**: CHECK — 삭제 안 된 댓글·답글은 1~1000자, 삭제된 것은 빈 글자.

## Success Criteria *(mandatory)*

- **SC-001**: 수용 시나리오가 모두 자동 테스트로 통과한다.
- **SC-002**: 권한 없는 삭제·남의 비공개 글 댓글 조작 중 성공하는 것이 0건이다.
