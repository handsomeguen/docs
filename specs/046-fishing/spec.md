# Feature Specification: 연못 낚시터

**Feature Branch**: `046-fishing`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "응 나머지 끝날때까지 쭉 진행해줘" (045 다음 마을 순서)

**다루는 명세 요구사항**: TOWN-14 연못 낚시터(하루 한 번, 물고기·장화는 코인, 먹이 꾸러미는 동물 먹이 1개, 오늘 결과·최근 7번 기록).

**명세와 다른 점**:
- 명세의 조사 버그(`🪙 30를`)는 처음부터 `withJosa`로 맞췄다(`🪙 30을`, `🪙 5를`, `🪙 1을`).
- 낚시터 자리는 광장 왼쪽(상점 맞은편) `POND_POS`(650, 760). 원래 농장 자리라는 설명은 044에서 농장을 광장 오른쪽 아래에 두어 해당 없음.
- 먹이 꾸러미를 낚으면 결과에 [🐮 동물 농장으로] 링크.
- 마을 건물 부제는 없다(다른 건물도 이름표 하나).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 하루 한 번 낚시 (Priority: P1) 🎯

1. 마을 광장 왼쪽 연못 앞에서 `🎣 낚시터 · Space 들어가기`. ☰ 바로 가기·텔레포트에도 🎣 낚시터. 방문자는 로그인 안내, `/fishing`은 첫 화면으로.
2. `연못에 낚싯대를 던져 볼까요?` [🎣 낚싯대 던지기](보내는 동안 `기다리는 중…`).
3. 송사리 🪙 5(25%)·붕어 🪙 15(30%)·잉어 🪙 30(15%)·황금 잉어 🪙 100(3%)·동물 먹이 꾸러미(15%)·낡은 장화 🪙 1(12%). 결과 문구와 `🪙 N을/를 받았어요.`(먹이면 `동물 먹이 1개를 받았어요.`), `내일 다시 낚시할 수 있어요.`
4. 다시 열면 버튼 없이 `오늘은 {이름}을/를 낚았어요.` 두 탭에서 동시에 던지면 하나만, 나머지는 `오늘은 이미 낚시했어요. 내일 다시 와 주세요!`
5. `🐟 낚을 수 있는 것` 6가지(확률은 숨김), `📒 최근 낚시 기록` 7개, 지갑 내역 `🎣 낚시`.
