# Feature Specification: 우리 집

**Feature Branch**: `037-house`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "계속 모든 작업이 끝날 때까지 쭉 진행해줘" (036 다음 게임 순서)

**다루는 명세 요구사항**: SHOP-05 가구 배치(칸·옮기기·비우기·예외 문구), TOWN-04 집 단계(`houseStage`, 이름 10개, 블로그 `🏠 우리 집` 줄), SIGNUP 기본 가구 2개(초록 화분·나무 의자를 0·1번 칸에), ERD `house_furniture`.

**명세와 다른 점**:
- 집 겉모습 그림(단계별 지붕·창문·탑 등), 지붕 색(TOWN-07), `🚪 밖으로` 문은 마을 단계에서 만든다. 지금은 방 안(벽·바닥·창문)과 가구 칸만 그린다.
- 가구 칸은 방 바닥에 한 줄(휴대폰 두 줄)로 놓인다. 칸 안 위치를 마음대로 옮기는 기능은 없다(명세와 같음).
- 마이그레이션 번호는 `0018_house`다(명세의 0026 대신).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 집 보기 (Priority: P1) 🎯

1. 블로그 홈 머리 아래에 `🏠 우리 집 · N단계 {집 이름}`과 `가구 n/m칸 · Lv.{다음 레벨}에 집이 커져요`(10단계는 뒷부분 없음).
2. 집 단계 `min(10, ⌊레벨 ÷ 10⌋ + 1)`, 칸 수 `min(8, 2 + 2 × 단계)` → 4·6·8칸.
3. 방문자도 같은 배치를 본다. 편집 버튼은 주인에게만.

### User Story 2 - 가구 놓기 (Priority: P1)

1. 주인이 [🛋 가구 놓기]를 누르면 빈 칸이 점선 `＋`. 칸을 누르면 `{n}번 칸에 놓을 가구를 골라 주세요`, 내 가구 목록과 [🧹 비우기], `가구는 상점에서 더 살 수 있어요.`
2. 다른 칸에 있는 가구를 고르면 옮겨 온다. 그 칸에 이미 있는 가구는 고를 수 없다. [✓ 다 놓았어요]로 끝낸다.
3. 예외: 없는 칸 `놓을 수 없는 자리예요.`, 가지지 않은 가구 `가진 가구만 놓을 수 있어요.`, 열리지 않은 칸 `Lv.{다음 레벨}이/가 되면 집이 커져서 이 자리를 쓸 수 있어요.` DB도 칸 0~7·가진 가구만·같은 가구는 한 칸에만을 막는다.
4. 상점에서 가구를 사면 `…우리 집에 놓아 보세요.`와 `🏠 우리 집으로` 링크.
