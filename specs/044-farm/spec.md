# Feature Specification: 동물 농장

**Feature Branch**: `044-farm`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "응 나머지 끝날때까지 쭉 진행해줘" (043 다음 마을 순서)

**다루는 명세 요구사항**: TOWN-09 동물 농장 1차(알 받기·랜덤 부화·돌보기 3가지·글쓰기 연동·다 키우면 보상과 카드, 한 번에 5마리), 마을의 농장 건물.

**명세와 다른 점**:
- 동물 종류는 테이블(`animal_species`)이 아니라 코드 상수(`src/lib/farm.ts` `SPECIES`)로 둔다. 키우는 동물은 `user_animals`가 아니라 `animals` 한 테이블(알이면 `species`가 비어 있음).
- 성장 아이템(먹이·고급 먹이·촉진제)과 [🌱 …] 버튼은 다음 단계(상점 성장 아이템·낚시터)에서 만든다.
- 블로그의 🏅 동물 도감과 한 마리 전시(BLOG-04)는 아직 없다. 다 키운 동물은 농장 화면의 🏅 다 키운 동물 카드에 모인다.
- 단계는 그림 크기로 나눈다(아기 56px·청소년 72px·어른 88px), 다 키운 카드에는 🎀 리본.
- 방문자가 `/farm`에 오면 다른 회원 화면처럼 첫 화면(로그인)으로 간다. 마을 농장 입구는 `· Space 로그인하고 이용하기`.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 알을 받아 키운다 (Priority: P1) 🎯

1. 마을 광장 오른쪽 아래(내 집으로 가는 길 오른쪽)의 빨간 헛간 앞에서 `🐮 동물 농장 · Space 들어가기`. ☰ 바로 가기·텔레포트에도 🐮 동물 농장.
2. [🎁 농장 첫 알 (무료)] 한 번, 레벨 5·10·15…마다 [🎁 레벨 N 보상 알 (무료)], [🪙 100으로 알 사기].
3. [🐣 부화시키기] → 병아리 40%·토끼 30%·아기 돼지 20%·송아지 10%.
4. [🥕 밥 주기] +10, [💧 물 주기] +10, [🤲 쓰다듬기] +5, 동물마다 하루 한 번씩, 돌볼 때마다 경험치 +2(하루 15번).
5. 보상 받는 공개 글(100자 이상)을 쓰면 키우는 동물이 모두 +10.
6. 다 차면 `🎉 {이름}이/가 다 자랐어요! 경험치 +N, 🪙 +N`, 🏅 다 키운 동물로 옮겨 가고 자리가 빈다.
7. 알·동물은 한 번에 5마리(`자리가 꽉 찼어요. 다 키운 뒤에 받을 수 있어요`).
