# Feature Specification: 프로필 사진

**Feature Branch**: `030-profile-photo`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "계속 진행해줘" (029 다음 순서, `plans/gap-survey-2026-10-12.md`의 블로그 쪽 마지막)

**다루는 명세 요구사항**: BLOG-03 열린 질문 "프로필 사진 올리기·지우기를 어디에 둘까?" → 👤 내 정보(`/settings/account`)에 두었다. BLOG-04 블로그 홈 프로필 사진, POST-07 첨부 규칙(프로필 사진 첨부는 누구나 보고, 글에 붙지 않고, 정리되지 않고, 글에 붙여 넣으면 새로 올린다), ERD 3.9 `profiles.photo_key`.

**명세와 다른 점**: 사진이 없을 때 명세는 캐릭터 얼굴을 보이지만 캐릭터(게임)가 아직 없어 닉네임 첫 글자 동그라미를 보인다. 사진은 블로그 홈 머리글에만 보인다(☰ 👤 내 프로필·마을 소식 카드에는 아직 없음). 자르기·돌리기 없이 올린 사진을 48px 동그라미에 채워(`object-cover`) 보인다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 내 얼굴 사진 걸기 (Priority: P1) 🎯

1. **Given** 👤 내 정보의 `프로필 사진` 칸, **When** [📷 사진 고르기]로 PNG·JPG·GIF·WEBP 사진(10MB까지)을 고르면, **Then** 올리고 바로 프로필 사진으로 정해 `프로필 사진을 바꿨어요`. 사진이 아니면 올리지 않고 `사진 파일이 아니에요...`.
2. 블로그 홈 머리글 블로그 이름 왼쪽에 48px 동그라미(대체 글 `{닉네임} 프로필 사진`). 사진이 없으면 닉네임 첫 글자 동그라미(화면 읽기 프로그램에는 숨김).
3. 로그인하지 않은 방문자도 프로필 사진 `/files/{키}`를 본다. 글에 붙지 않은 다른 첨부는 여전히 올린 사람만 본다.
4. 사진을 바꾸면 전 사진은 떨어진 첨부가 되어 방문자는 더 못 보고, 하루 뒤 `posts:cleanup`이 지운다. 지금 프로필 사진은 오래돼도 지우지 않는다.
5. [사진 지우기] → `프로필 사진을 지울까요?` 확인하면 첫 글자 동그라미로 돌아간다. 취소하면 그대로다.

### User Story 2 - 규칙 지키기 (Priority: P2)

1. 내 프로필 사진 주소를 글에 붙여 넣으면 새 키로 다시 올라가 그 글에 붙고, 프로필 사진은 그대로다. 저장 요청에 프로필 사진 키를 섞어도 글에 붙지 않는다.
2. 남이 올린 첨부, 글에 붙은 첨부, 사진이 아닌 첨부, 1시간 넘게 지난 첨부의 키로는 프로필 사진을 바꿀 수 없다: `이 사진은 프로필 사진으로 쓸 수 없어요. 다시 올려 주세요.`
3. 탈퇴하면 프로필과 사진 첨부가 함께 지워진다.
