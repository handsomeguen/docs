# Quickstart: 사진·파일 첨부

001과 같이 띄운 뒤 (`npm run db:migrate`로 `0002_attachments` 적용):

1. 로그인 → [✏️ 글쓰기] → [🖼 사진]으로 사진 두 장 → 본문에 두 장 → [발행하기] → 상세에서 보인다.
2. 스크린샷을 복사해 본문에 붙여 넣기, 파일을 끌어다 놓기.
3. [📎 파일]로 PDF → 카드 → 발행 → 카드를 누르면 원래 이름으로 내려받는다.
4. 시크릿 창에서 공개 글 사진 주소 열림 → 글을 비공개로 바꾸면 404.
5. `npm run posts:cleanup -- --dry-run` → 지울 개수만 출력.

파일은 `storage/uploads/`(git 제외)에 쌓인다. `UPLOAD_DIR`로 바꿀 수 있다.
