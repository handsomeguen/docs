# Feature Specification: 옷가게

**Feature Branch**: `059-clothes` (코드: handsomeguen/blogville PR #9)

**Created**: 2026-10-13

**Status**: Implemented

**Input**: User description: "이전에 남았던 pr 이어서 계속 진행해줘 1시까지"

**다루는 명세 요구사항**: SHOP-08 옷가게(거울로 미리 입어 보고, 안 가진 것만 한 번에 사서 입기, 새 옷 6벌·모자 3개).

**명세와 다른 점**:
- 광장의 옷가게 **건물은 아직 없다**. 마을 ☰ 바로 가기 `👗 옷가게`, 상점 화면 안내 줄, 주소 `/clothes`로 들어간다. 건물은 마을 배치를 바꾸는 내 정원(TOWN-20) 단계에서 미용실과 함께 놓는다.
- 미용실(SHOP-07)·머리 모양·머리 색(`hair`·`hair_color` 부위, 마이그레이션 0031)은 이 단계에 없다. 그래서 공통 화면 `style-studio.tsx` 대신 옷가게 전용 `src/components/clothes/ClothesStudio.tsx`, 계산은 `src/lib/clothes.ts`(`outfitBill`·`parseOutfit`), 처리는 `src/server/clothes.ts`(`applyOutfit`), 마이그레이션은 `0024_clothes_shop`.
- 탭 첫 카드는 `안 입기`·`안 쓰기`·`안 하기`(부위마다). 버튼 문구는 `🪙 {합계} 내고 입기` / `✨ 입기` / `지금 모습이에요` / `🔒 Lv.N부터 살 수 있어요` / `코인이 N개 부족해요`. 산 뒤 문구는 `🎉 {이름}을/를 🪙 {합계}에 샀어요. 새 옷이 잘 어울려요!`(여럿이면 `{첫 이름} 외 N개`), 산 것 없이 바꾸면 `✨ 새 옷이 잘 어울려요!`.
- 옷가게 카드에는 새 9개뿐 아니라 상점에서 파는 모자·옷·소품과 내가 가진 아바타 아이템도 함께 나온다(거울로 맞춰 입기). 새 9개는 상점 목록·상점 구매에서는 빠진다(`CLOTHES_SHOP_ONLY`).
- 원장은 산 아이템마다 `purchase` 한 줄(아이템 ID, 상점과 같은 고유 규칙).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 입어 보고 사기 (Priority: P1) 🎯

1. `/clothes`(`👗 꼬까 옷가게`) 왼쪽 거울에 내 캐릭터가 걷는 모습으로 보인다. [앞·왼쪽·뒤·오른쪽]으로 돌리고 [⏸ 멈춤 / ▶ 걷기]를 바꾼다.
2. 오른쪽 탭(👕 옷 · 🎩 모자 · 👓 소품)에서 카드를 누르면 거울이 바로 그 모습이 된다. 카드에는 그 아이템을 입힌 내 캐릭터, 이름, `🪙 가격`·`보유 ✓`·`입는 중 ✓`·`🔒 Lv.N`.
3. 🧾 계산서에 새로 살 것과 합계. 버튼을 누르면 한 번에 사고 입는다. 헤더·마을 캐릭터도 바뀐다.

### 예외

- 코인 부족·레벨 부족이면 버튼이 꺼진다. 합계를 조작해 보내면 `가격이 바뀌었어요. 화면을 새로 고쳐 주세요`, 다른 부위·없는 아이템이면 `이 가게에서 고를 수 없는 아이템이에요`, 서버가 다시 확인한 레벨·코인 부족도 같은 문구. 아무것도 바뀌지 않는다.
- 방문자는 첫 화면으로.
