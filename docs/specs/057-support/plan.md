# Implementation Plan: 버그·문의

**Branch**: `feature/support` | **Spec**: [spec.md](spec.md)

- DB: 새 표 `feedback`(`user_id` → users ON DELETE CASCADE, `kind` CHECK `bug`·`question`, `title` 1~100자·`content` 1~2000자 CHECK, `page_path`(2048자까지)·`user_agent`(300자까지), `status` CHECK 4가지 기본 `new`, 답변 `reply`·`replied_at`·`replied_by`(`admin`·`bot`) 묶음 CHECK, `created_at`·`updated_at`, 인덱스 `(status, created_at)`·`(user_id, created_at desc)`). `notifications`에 `feedback_id`(→ feedback CASCADE, 인덱스), 종류 CHECK에 `feedback_reply`, 모양 CHECK에 "문의 답변 알림은 행동한 사람·글·방명록 글 없이 문의만"(다른 종류는 `feedback_id`가 비어야 함). 마이그레이션 `0028_support` (표·인덱스·외래 키·CHECK만, `CREATE SCHEMA` 없음).
- 순수 함수: `src/lib/support-rules.ts` — 종류·상태와 글자, `checkFeedback`, `checkReply`, `feedbackPagePath`(`safeNext`), `truncateUserAgent`, `rateWindowStart`·`isRateLimited`(한 시간 5번), `nextStatus`, `shouldNotifyReply`, `parseStatusList`·`parseLimit`, `supportHref`. `src/lib/releases.ts` — `hasNewRelease`(3일). `src/lib/notifications.ts` — `feedbackNotificationText`, `FEEDBACK_NOTIFICATION_HREF`.
- 서버: `src/server/feedback.ts` — `createFeedback`(회원 행 잠금 → 한 시간 수 → 저장), `listMyFeedback`, `listFeedbackForAdmin`, `countNewFeedback`, `listFeedbackForBot`, `updateFeedback`(행 `FOR UPDATE` → 상태·답변 → 같은 트랜잭션에서 `notifyFeedbackReply`). `src/server/feedback-bot.ts` — `checkBotToken`(`disabled`·`unauthorized`·`ok`, SHA-256 + `timingSafeEqual`). `src/server/feedback-api.ts` — 공통 응답과 `guardBot`. 알림 조회는 `feedback`을 이어 제목을 가져온다.
- Action: `src/app/support/actions.ts` `sendFeedback`(`requireMember` → `checkFeedback` → `headers()`의 User-Agent → `createFeedback` → `revalidatePath("/support")`), `src/app/admin/actions.ts` `adminUpdateFeedback`(`requireAdmin` → `parseId`·상태·`checkReply`, 화면이 열릴 때 상태와 같으면 상태를 고르지 않은 것으로).
- Route Handler: `src/app/api/feedback/route.ts`(GET), `src/app/api/feedback/[id]/route.ts`(POST, zod `strictObject`). 쿠키·세션은 보지 않는다. 다른 방법은 404.
- 화면: `src/app/layout.tsx` 아래 막대(`SupportLink` 클라이언트 `usePathname`, `UpdatesNewBadge` 서버 + Suspense), `src/app/support/page.tsx`, `src/components/support/SupportForm.tsx`(`useActionState`, 칸은 상태로 쥐어 실패 때 남김)·`FeedbackStatusBadge.tsx`, `src/app/admin/feedback/page.tsx`, `src/components/admin/FeedbackAdminForm.tsx`, `/admin` 새 문의 수, 마을 ☰ 메뉴 링크, 알림함·☰ 최근 알림 문구.
- 배포: `.env.example`, `.github/workflows/deploy.yml`(`secrets.FEEDBACK_BOT_TOKEN` → `envs`), `deploy/run.sh`(값이 있을 때만 `app.env`에 한 줄).
