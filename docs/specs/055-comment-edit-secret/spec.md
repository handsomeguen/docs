# Feature Specification: 댓글 수정·비밀 댓글

**Feature Branch**: `055-comment-edit-secret` (코드: handsomeguen/blogville `055-comment-edit-secret`)

**Created**: 2026-10-13

**Status**: Implemented

**Input**: 블로그로서 아쉬운 기능 보강 (54단계에 이어서)

**다루는 명세 요구사항**: SOC-01 댓글, SOC-02 답글. SOC-01 열린 질문 "댓글 수정이 필요할까?"에 답한다.

**명세와 다른 점**:
- 4단계(`specs/004-comments`)는 "댓글 수정은 명세대로 없다"였다. 이제 **작성자 본인**이 자기 댓글·답글을 고칠 수 있다. 블로그 주인·관리자는 남의 댓글을 지울 수만 있고 고칠 수는 없다.
- 명세에 없던 **비밀 댓글**(티스토리처럼)을 더했다. 댓글·답글 입력칸에 `🔒 비밀 댓글` 체크.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 내 댓글 고치기 (Priority: P1) 🎯

1. 내가 쓴, 지우지 않은 댓글·답글 아래에 [수정]이 보인다 (다른 사람에게는 없다).
2. [수정]을 누르면 내용 자리에 지금 내용이 채워진 입력칸(`댓글 수정`, 3줄)이 열리고 커서가 간다. 아래에 `🔒 비밀 댓글` 체크, [취소] [저장].
3. [저장]하면 입력칸이 닫히고 고친 내용이 보인다. 시각 옆에 `(수정됨)`(마우스를 올리면 고친 시각).
4. [취소]나 Esc를 누르면 그대로 닫히고 초점은 [수정]으로 돌아온다.

- 내용 규칙은 댓글 쓰기와 같다 (1~1000자, `checkComment`). 빈 칸이면 `댓글을 적어 주세요`, 쓴 내용은 남는다.
- 비밀 체크만 켜고 끈 경우(내용이 같으면) `(수정됨)`은 붙지 않는다.
- 남의 댓글, 지운 댓글, 볼 수 없게 된 글의 댓글, 이상한 ID로 요청을 조작하면 `수정할 수 있는 댓글이 없어요`, 아무것도 바뀌지 않는다. ID가 정수가 아니면 `잘못된 요청이에요`.
- 고칠 사람은 로그인 세션으로만 정한다. 로그인이 풀려 있으면 첫 화면으로 간다 (`requireMember`).

### User Story 2 - 비밀 댓글 (Priority: P1)

1. 댓글·답글 입력칸의 `🔒 비밀 댓글`을 체크하고 등록하면 비밀 댓글이 된다. 볼 수 있는 사람에게는 시각 옆에 🔒가 보인다.
2. 볼 수 없는 사람에게는 닉네임·시각은 그대로, 내용 자리에 `🔒 비밀 댓글이에요`(흐린 기울임)만 보이고 버튼이 없다 ([답글] 포함).
3. 수정할 때 비밀을 켜고 끌 수 있다.

**누가 보나**

| 줄 | 내용을 보는 사람 |
|---|---|
| 비밀 댓글 | 댓글 작성자, 블로그 주인, 관리자 |
| 비밀 댓글 밑의 답글 (비밀 체크와 상관없이) | 원댓글 작성자, 그 답글 작성자, 블로그 주인, 관리자 |
| 비밀 답글 | 답글 작성자, 원댓글 작성자, 블로그 주인, 관리자 |

- 내용은 **서버가 비워서** 보낸다 (`getCommentThread`). 볼 수 없는 사람의 HTML·RSC 데이터에 내용이 없다.
- 볼 수 없는 비밀 댓글에는 답글을 달 수 없다 ([답글] 없음, 요청을 조작하면 `답글을 달 댓글이 없어요`).
- `💬 댓글 N`과 글 목록 카드의 `💬 N`은 비밀 댓글도 센다 (지금처럼).
- 블로그 옆 칸 `💬 최근 댓글`: 비밀 댓글을 목록에서 빼지 않고, 볼 수 없는 사람에게는 내용 대신 `🔒 비밀 댓글이에요`를 보여 준다 (내용은 SQL에서 비운다). 링크는 그 댓글 자리로 그대로 간다.
- `💬 댓글 관리`(`/settings/comments`)는 블로그 주인 화면이라 내용을 그대로 보이고 🔒 표시만 붙인다.
- 알림에는 원래 댓글 내용이 없어서 바뀐 것이 없다 (글 주인·원댓글 작성자는 알림을 받는다). RSS에는 댓글이 없다.

## Success Criteria *(mandatory)*

- **SC-001**: `tests/unit/comment-rules.test.ts`의 비밀 규칙(`canSeeSecret`·`isCommentHidden`·`isReplyHidden`) 3개와 `tests/e2e/comment-edit-secret.spec.ts` 5개가 통과하고, 댓글·옆 칸·알림·댓글 관리·탈퇴 시험이 그대로 통과한다.
- **SC-002**: 비밀 댓글을 볼 수 없는 회원·방문자가 받은 글 상세와 블로그 홈 HTML에 그 내용이 없다.
- **SC-003**: 남의 댓글 ID로 바꾼 수정 요청은 블로그 주인이 보내도 DB를 바꾸지 않는다.
