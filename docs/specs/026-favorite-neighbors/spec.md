# Feature Specification: 즐겨찾는 이웃 ⭐

**Feature Branch**: `026-favorite-neighbors`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "계속 진행해줘" (025 다음 순서, `plans/gap-survey-2026-10-12.md` 13번)

**다루는 명세 요구사항**: TOWN-08 즐겨찾는 이웃(⭐ 최대 10명, 공지 블로그 제외), SOC-04 이웃 새 글의 "최근 7일 안의 즐겨찾는 이웃 글 먼저"와 `⭐ 즐겨찾는 이웃` 배지.

**명세와 다른 점**:
- 마을(☰ 👫 친구 목록)이 아직 없어 ⭐는 이웃 새 글 위 `👫 내 이웃` 목록(018)의 줄마다 둔다. 위 문구도 마을 대신 `⭐ 즐겨찾는 이웃의 최근 7일 글이 이웃 새 글 맨 위에 보여요 ({n}/10)`.
- 목록 순서는 즐겨찾기 먼저, 그다음은 018대로 최근 공개 글 순(명세 친구 목록은 닉네임 순).
- 공지 블로그 거절 문구는 마을 이야기를 빼고 `공지사항 블로그는 즐겨찾기할 수 없어요.` 📢에도 같은 설명.
- 거절 문구는 그 줄 아래에 보인다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 즐겨찾는 이웃 고르기 (Priority: P1) 🎯

1. **Given** 내 이웃 목록, **Then** 줄마다 ☆(44 × 44px), 위에 `({n}/10)`. ☆를 누르면 ⭐로 바뀌고 그 줄이 맨 위로, 다시 누르면 꺼진다.
2. **Given** 즐겨찾기 10명, **When** 11번째 ☆, **Then** `즐겨찾기는 10명까지예요. 다른 이웃의 ⭐를 먼저 꺼 주세요.` 저장되지 않는다. 하나를 끄면 켤 수 있다.
3. **Given** 이웃이 아니거나 나 자신인 ID를 조작해 보냄, **Then** `이웃으로 추가한 사람만 즐겨찾기할 수 있어요.` 1~64자 문자열이 아니면 `이웃을 찾을 수 없어요.`
4. **Given** 공지사항 블로그(`/@notice`), **Then** ☆ 대신 📢. 조작해 보내도 `공지사항 블로그는 즐겨찾기할 수 없어요.` 이미 켜 둔 ⭐는 끌 수 있고 10명에 세지 않는다.
5. **Given** 이웃을 취소함, **Then** 즐겨찾기도 풀린다(다시 이웃 추가하면 ☆).
6. 같은 회원이 동시에 눌러도 10명을 넘지 않는다(회원별 잠금, 코드 확인).

### User Story 2 - 이웃 새 글 맨 위 (Priority: P1)

1. **Given** 즐겨찾는 이웃이 최근 7일(한국 날짜, 오늘 포함) 안에 쓴 공개 글, **Then** 이웃 새 글 맨 위에 노란 `⭐ 즐겨찾는 이웃` 배지와 함께 보이고, 그 아래 나머지가 시간 순. 예: 즐겨찾기 3일 전 → 다른 이웃 어제 → 즐겨찾기 10일 전.
2. 6일 전 0시 이후 글은 맨 위 묶음, 7일 전 글은 일반 순서.
3. 마을 소식·마을 검색에는 배지가 없다.
