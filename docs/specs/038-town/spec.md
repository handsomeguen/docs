# Feature Specification: 마을 광장

**Feature Branch**: `038-town`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "계속 모든 작업이 끝날 때까지 쭉 진행해줘" (037 다음 게임 순서)

**다루는 명세 요구사항**: TOWN-01 마을 `/town`(방문자도 구경, 휴대폰은 게임 없음), TOWN-02 캐릭터 이동(방향키·WASD·클릭, 부딪힘, 카메라), TOWN-03 건물에 들어가기(게시판·상점·집, 방문자 로그인 안내), TOWN-04 이웃집(회원은 즐겨찾는 이웃 10채, 방문자는 인기 100곳 중 무작위 10채), TOWN-11 집 단계 그림 10가지.

**명세와 다른 점**:
- 게임 엔진(Phaser) 없이 캔버스 하나에 직접 그린다. 새 라이브러리를 들이지 않고, 도트 그림은 캐릭터와 같은 글자 그림 방식이다.
- 마을은 2000 × 1600 평면이다. 높낮이·계단·연못(2.5D, TOWN-05), 내 정원(TOWN-20), 낚시터·농장·미용실·옷가게, 집 앞 우체통(TOWN-13)은 다음 단계에서 만든다. 지금 건물은 게시판(마을 소식·출석 체크 입구 둘), 상점, 분수, 가로등, 집 11자리, 나무다.
- 마을에도 지금의 헤더 막대가 그대로 있다(☰ 마을 메뉴 TOWN-12가 아직 없어서). 헤더에 `🏘 마을` 링크를 더했고, 명세의 [← 광장으로 나가기] 대신이다.
- 로그인 직후 가는 곳은 아직 내 블로그다(AUTH-09의 `/town`은 ☰ 메뉴와 함께 바꾼다). 마을 환영 문구(`?welcome`)도 그때.
- 캐릭터는 64px(도트 16칸 × 4)이고 걸을 때 통통 튀며 왼쪽으로 가면 뒤집힌다. 방향별 걷기 그림(TOWN-17)과 태블릿 조이스틱은 아직 없다(탭으로 걷기는 된다).
- 지붕 색은 블로그 번호로 10가지 중 하나다(고르기 TOWN-07은 다음 단계).
- 휴대폰 조건은 폭 640px 미만만 본다(낮은 가로 화면 조건은 아직).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 마을 걷기 (Priority: P1) 🎯

1. 헤더 `🏘 마을`이나 블로그 우리 집의 `🚪 밖으로`로 `/town`에 간다. 방문자도 들어간다(회색 주민, 이름표 `구경하는 중`).
2. 방향키·WASD로 걷고(대각선도 같은 속도), 땅을 누르면 그곳까지 걷는다. 건물·집·분수·가로등·나무에 막히고 마을 밖으로 못 나간다. 카메라가 따라간다.
3. 앞에 있는 것이 위에 그려진다(아랫변 순서). 글자 칸·버튼 위의 키는 게임이 가져가지 않는다.

### User Story 2 - 들어가기 (Priority: P1)

1. 입구 90px 안이면 위에 `{아이콘} {이름} · Space 들어가기`. Space·Enter로 들어간다. 멀리서 누른 키는 버린다.
2. 게시판 왼쪽 `📋 마을 소식` → `/feed`, 오른쪽 `📮 출석 체크` → `/attendance`, `🏪 상점` → `/shop`, 집 → 그 블로그.
3. 방문자의 출석 체크·상점은 `· Space 로그인하고 이용하기`, 누르면 첫 화면.
4. 건물을 누르면 가까우면 바로 들어가고, 멀면 입구까지 걷는다.

### User Story 3 - 집 (Priority: P1)

1. 집 자리 11곳: 0번 내 집(광장 아래), 1~10번 즐겨찾는 이웃의 집(먼저 이웃이 된 순서, 공지 블로그 제외). 빈 자리는 `빈 집터`(0번은 `내 집 자리`).
2. 방문자: 공개 글이 있는 블로그 중 누적 방문자 수 → 최근 공개 글 순 100곳에서 무작위 10채.
3. 집 그림은 주인 레벨의 단계 10가지, 이름표 `내 집`/`{닉네임}의 집`(12자 넘으면 …)과 블로그 이름.
4. `/town?at={블로그 주소}`면 그 집 앞에서 시작한다.

### User Story 4 - 휴대폰 (Priority: P2)

폭 640px 미만: 회원의 `/town`은 내 블로그로, 방문자는 `🏘 Blogville 마을 구경` 간단 메뉴. `🚪 밖으로`·`🏘 마을`은 숨긴다.
