**다루는 명세 요구사항**: SHOP-07 미용실(거울로 미리 보며 머리 모양 7가지·머리 색 8가지를 고르고, 안 가진 것만 한 번에 사서 바꾸기).

**명세와 다른 점**:
- 광장의 미용실 **건물은 아직 없다**. 마을 ☰ 바로 가기 `💇 미용실`과 주소 `/salon`으로 들어간다. 건물은 내 정원(TOWN-20) 단계에서 옷가게와 함께 놓는다.
- 마이그레이션은 0031이 아니라 `0025_salon`(아이템 종류·착용 부위에 `hair`·`hair_color` 추가, 머리 15가지 넣기). 기본 머리(짧은 머리·단발)와 기본 색(밤색·흑발)은 0코인이고 팔지 않는 표시(`is_on_sale = false`)지만 미용실에는 나오고 무료로 받는다(원장 줄 없음).
- 공통 화면 `style-studio.tsx` 대신 미용실 전용 `src/components/salon/SalonStudio.tsx`(옷가게 화면과 같은 거울·탭·계산서), 계산 `src/lib/salon.ts`(`styleBill`), 처리 `src/server/salon.ts`(`applyStyle`).
- 머리 그림은 캐릭터 그림 위에 얹는 덧그림이다. 머리를 고르면 캐릭터의 원래 머리를 지우고(`~bald`) 새 머리를 그린다. 머리 색은 원래 머리나 새 머리 색을 바꾼다(`~#색`). 쌓는 순서: 몸 → 옷 → 머리 → 소품 → 모자.
- 머리 모양·색은 사람 캐릭터(남자아이·여자아이)에만 보인다. 동물 캐릭터면 미용실에 안내(`data-salon-animal`)가 나오고 거울은 남자아이 모습으로 보여 준다. 사서 적용해 두면 사람 캐릭터로 바꿨을 때 보인다.
- 머리는 미용실에서만 판다(상점 목록·상점 구매에서는 `hair`·`hair_color` 종류를 뺀다). 옷가게 거울에도 지금 머리가 함께 보인다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 머리 바꾸기 (Priority: P1) 🎯

1. `/salon`(`💇 반짝 미용실`) 거울에 내 캐릭터가 걷는 모습으로 보인다. [앞·왼쪽·뒤·오른쪽], [⏸ 멈춤 / ▶ 걷기].
2. 탭 `💇 머리 모양` · `🎨 머리 색`. 첫 카드는 `원래 머리` / `원래 색`. 카드를 누르면 거울이 바로 바뀐다.
3. 🧾 계산서의 버튼 `🪙 {합계} 내고 적용하기`(무료면 `✨ 적용하기`)로 한 번에 사서 적용한다. 산 뒤 `새 머리가 잘 어울려요!`. 마을·옷가게 거울·집 카드에도 새 머리가 보인다.

### 예외

- 코인·레벨 부족이면 버튼이 꺼진다. 합계 조작·다른 부위·없는 아이템은 거절하고 아무것도 바뀌지 않는다(옷가게와 같은 문구).
- 방문자는 첫 화면으로.
