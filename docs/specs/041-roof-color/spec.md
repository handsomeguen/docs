# Feature Specification: 지붕 색 고르기

**Feature Branch**: `041-roof-color`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "응 나머지 끝날때까지 쭉 진행해줘" (040 다음 마을 순서)

**다루는 명세 요구사항**: TOWN-07 내 집 지붕 색(10색, 가입 때 무작위 1색, 집 단계마다 1색씩 열림, 우리 집 [🏠 지붕 색] 고르기 창, 마을의 내 집 지붕).

**명세와 다른 점**:
- 마이그레이션은 `0019_roof_color`(명세의 `0013`·`0029`는 옛 코드 번호). 그림 함수는 `houseSvg` 대신 038의 도트 `houseArt`, 고르기 창 미리 보기도 같은 그림.
- 색 hex는 새로 정했다(038의 임시 10색 중 진남색 대신 주황·하늘을 넣어 코드값 10개와 맞춤). 038에서 블로그 번호로 정하던 지붕 색은 이제 블로그마다 섞은 순서의 첫 색이라 기존 집의 지붕 색이 바뀔 수 있다.
- 친구 마을 구경(TOWN-15)은 아직 없어 내 마을·나를 즐겨찾는 회원의 마을·방문자 마을에 보인다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 지붕 색 고르기 (Priority: P1) 🎯

1. 내 블로그 "🏠 우리 집"의 [🏠 지붕 색](주인에게만)을 누르면 고르기 창: 지금 지붕의 집 그림, `광장에 보일 지붕 색을 골라 주세요`, `처음 색은 무작위로 받았어요. 집이 한 단계 클 때마다 색이 하나씩 늘어요 (N/10색).`
2. 열린 색은 44px 동그라미(지금 색에 ✓), 잠긴 색은 점선 동그라미 🔒와 `Lv.10`…`Lv.90`. 열린 색을 누르면 바로 저장, [✓ 다 골랐어요]로 닫는다.
3. 고른 색이 마을의 내 집 지붕(내 마을, 나를 즐겨찾는 회원의 마을, 방문자 마을)에 보인다. 안 골랐으면 순서의 첫 색.

### 예외

- 목록에 없는 색: `고를 수 없는 색이에요.` / 열리지 않은 색: `아직 열리지 않은 색이에요. 집이 한 단계 클 때마다 색이 하나씩 늘어요.` DB CHECK가 다른 값을 거부한다.
