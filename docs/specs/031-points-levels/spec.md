# Feature Specification: 경험치·레벨·코인과 보상

**Feature Branch**: `031-points-levels`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "계속 진행해줘" + 결정 카드 "단순 도트" (블로그 쪽이 끝나 게임을 시작한다. 그림이 필요 없는 원장·레벨·코인부터)

**다루는 명세 요구사항**: GAME-02 경험치와 레벨, GAME-03 코인, GAME-05 보상 규칙과 하루 상한(가입·글·댓글·답글·공감 받음), GAME-07 경험치·코인 내역, POST-01 글쓰기 보상 안내·발행 안내의 보상 문구, ERD 3.5 `point_ledger`.

**명세와 다른 점**:
- 출석(GAME-04), 레벨업 팝업·알림(GAME-06), 캐릭터(GAME-01), 동물·낚시·상점은 아직 없어 원장 사유는 `signup`·`post`·`comment`·`like_received` 네 가지뿐이다(CHECK로 막음). 다음 단계에서 넓힌다.
- 원장이 생기기 전에 가입한 회원에게도 가입 축하 🪙 100을 가입 시각으로 넣었다(마이그레이션). 가입 축하는 회원마다 한 번(부분 고유 인덱스 `point_ledger_signup_uq`).
- 하루 상한에 걸려 보상을 못 받은 공감은 "그 사람·그 글"을 다 쓴 것으로 치지 않는다. 다음 날 껐다 켜면 그때 받을 수 있다(원장에 보상 없는 줄을 남기지 않아서).
- 헤더는 `Lv.N 🪙 N` 한 덩어리 링크로 `/wallet`에 간다(캐릭터 얼굴은 아직 없음). 내역 화면 맨 아래는 상점이 없어 `코인은 상점이 열리면 쓸 수 있어요.`(링크 없음).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 활동하면 경험치·코인이 쌓인다 (Priority: P1) 🎯

1. 가입하면 원장 `signup` 🪙 100, 헤더 `Lv.1 🪙 100`.
2. 글쓰기 아래 `N자` 옆 안내: 공개·100자 이상이면 `· 저장하면 ✨ 경험치 30 · 🪙 30 보상 (하루 3번까지)`, 100자 미만 `· 100자 이상 쓰면 보상을 받아요`, 비공개 `· 비공개 글은 보상이 없어요`. 고칠 때는 안내 없음.
3. 공개 새 글(본문 100자 이상)은 ✨ 30 · 🪙 30, 하루 3번. 발행 안내가 `🎉 글을 발행했어요! ✨ 경험치 30 · 🪙 30 코인을 받았어요` / `(비공개 글, 짧은 글, 또는 오늘 글쓰기 보상 3번을 다 받아서 보상은 없어요)`. 고친 글·비공개 글·짧은 글은 보상 없음.
4. 남의 글에 쓴 댓글·답글은 ✨ 5 · 🪙 5, 합쳐 하루 10번. 내 글에는 없음.
5. 남이 내 글에 공감하면 ✨ 2 · 🪙 2, 하루 20번. 같은 사람이 같은 글에 껐다 켜도 한 번(DB 부분 고유 인덱스도 막음). 내 공감은 없음.
6. "하루"는 한국 시간 0시 기준. 같은 회원의 보상은 회원 단위 잠금으로 줄을 세워 상한을 넘지 않는다.
7. 레벨은 누적 경험치로만 계산한다: 레벨 n은 `10 × n × (n − 1)` 이상, 최고 99.

### User Story 2 - 내역 보기 (Priority: P2)

1. 헤더 `Lv.N 🪙 N` → `/wallet` `📒 경험치·코인 내역`, `기록 N개`.
2. 요약 3칸 `레벨`·`누적 경험치`·`코인`, 다음 레벨까지 막대(`현재 / 필요 EXP`, 최고면 `최고 레벨`).
3. 기록은 최신순 20개씩: 활동 이름(🎉 가입 축하 · ✏️ 글 작성 · 💬 댓글 작성 · ♥ 공감 받음), `YYYY. MM. DD. HH:MM`, ✨ +N(하늘색), 🪙 ±N(초록/빨강), 0인 쪽은 생략.
4. 방문자는 첫 화면으로. 375px에서 가로 스크롤 없음.
