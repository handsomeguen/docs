# Feature Specification: 방명록

**Feature Branch**: `056-guestbook` (코드: handsomeguen/blogville `056-guestbook`)

**Created**: 2026-10-13

**Status**: Implemented

**Input**: 블로그로서 아쉬운 기능 보강 (55단계에 이어서). 티스토리의 방명록처럼

**다루는 명세 요구사항**: 새 요구사항 **BLOG-10 방명록**. GAME-08 알림에 방명록 알림 2가지를 더한다.

**명세와 다른 점**: 명세에 없던 기능이다. 방명록 글에는 보상(GAME-05)이 없다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 방명록 남기기 (Priority: P1) 🎯

1. 블로그 옆 칸 맨 위의 `📖 방명록 N`(또는 주인 도구 막대의 `📖 방명록 N`)을 누르면 `/@주소/guestbook`이 열린다. 위쪽에 블로그 이름(누르면 블로그 홈)과 `📖 방명록 N`.
2. 회원은 입력칸(`방명록`, 3줄)에 적고 [방명록 남기기]를 누른다. 맨 위에 새 글이 나오고 입력칸이 빈다.
3. 글은 최신순 10개씩, `?page=N` (공용 쪽 번호). 없으면 `아직 방명록이 없어요`.
4. 방문자에게는 입력칸 대신 `로그인하면 방명록을 남길 수 있어요`. [로그인]은 로그인 뒤 이 방명록으로 돌아온다 (`/?next=/@주소/guestbook`).

- 내용 규칙·문구는 댓글과 같다 (1~1000자, `checkComment`: `댓글을 적어 주세요`, `댓글은 1000자까지예요`). 쓴 내용은 남는다.
- 블로그 주인도 자기 방명록에 쓸 수 있다 (티스토리처럼). 이때는 알림이 없다.
- `blogId`가 정수가 아니면 `잘못된 요청이에요`, 없는 블로그면 `블로그를 찾을 수 없어요`.

### User Story 2 - 고치기·지우기 (Priority: P1)

1. 작성자에게만 [수정]: 채워진 입력칸(`방명록 수정`), 자동 초점, Esc·[취소]로 닫기, [저장]. 내용이 바뀌면 시각 옆 `(수정됨)`.
2. [삭제]는 작성자, 블로그 주인, 관리자에게 보인다. 확인 창(`방명록 글을 삭제할까요?`) 뒤 행을 지운다 (주인 답글도 함께).
- 남의 글 ID로 조작한 수정은 `수정할 수 있는 방명록 글이 없어요`, 삭제는 아무것도 바꾸지 않는다.

### User Story 3 - 🔒 비밀글 (Priority: P1)

1. 입력칸의 `🔒 비밀글`(44px)을 체크하면 비밀글. 볼 수 있는 사람에게는 시각 옆 🔒.
2. 내용은 **작성자·블로그 주인·관리자**만 본다. 나머지에게는 닉네임·시각과 `🔒 비밀 방명록이에요`만, 버튼이 없다.
3. 주인 답글도 글을 따른다: 가려진 글의 답글은 내용 대신 같은 문구.
- 내용은 서버가 비워 보낸다 (`getGuestbook`). 볼 수 없는 사람의 HTML·RSC 데이터에 내용이 없다.
- `📖 방명록 N`은 비밀글도 센다.

### User Story 4 - 주인 답글 (Priority: P2)

1. 블로그 주인에게 글마다 [답글]. 입력칸(`방명록 답글`)에 1~1000자, [답글 등록]. 글 아래 들여쓴 `↳ 주인 닉네임` 줄로 보인다. 답글은 한 글에 하나, 1단계.
2. 주인은 [답글 수정](바뀌면 `(수정됨)`)·[답글 삭제]를 한다. 관리자는 [답글 삭제]만.
- 주인이 아니면 [답글]이 없다. 조작한 요청은 `답글을 달 방명록 글이 없어요`, DB는 그대로 (관리자도 남의 방명록에는 답글을 못 단다).

### User Story 5 - 알림 (Priority: P2)

- 남이 내 방명록에 글을 쓰면 주인에게 `📖 {닉네임}님이 방명록에 글을 남겼어요`.
- 주인이 처음 답글을 달면 작성자에게 `📖 {닉네임}님이 내 방명록 글에 답글을 달았어요` (고칠 때는 다시 오지 않는다).
- 누르면 그 블로그의 방명록(`/@주소/guestbook`)으로. 방명록 글이 지워지면 알림도 지워진다. 마을 ☰ 메뉴 최근 알림에도 같은 문구.

### 탈퇴 (AUTH-06)

- 탈퇴한 회원이 쓴 방명록 글은 지워진다 (답글과 알림도). 댓글과 달리 남의 답글이 매달리지 않으므로 자리를 남기지 않는다. 블로그가 지워지면 그 방명록도 지워진다.

### 화면

- 375px에서 가로 스크롤이 없고 버튼·체크 영역은 44px 이상. 키보드로 [수정]·[답글]을 열고 Esc로 닫으면 초점이 그 버튼으로 돌아온다.

- **SC-002**: 비밀 방명록을 볼 수 없는 회원·방문자가 받은 방명록 HTML에 글과 답글 내용이 없다.
- **SC-003**: 남의 글 수정·삭제, 주인이 아닌 답글, 없는 블로그로 바꾼 요청은 DB를 바꾸지 않는다.
