# Feature Specification: 꾸미기

**Feature Branch**: `036-closet`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "계속 모든 작업이 끝날 때까지 쭉 진행해줘" (035 다음 게임 순서)

**다루는 명세 요구사항**: SHOP-04 장착(`/closet`, 배경), SHOP-06 아바타 꾸미기(모자·옷·소품 부위마다 하나, 다시 누르면 벗기), BLOG-04 미니룸(건 배경 위 캐릭터), ERD `avatar_equips`·`blogs.background_item_id`.

**명세와 다른 점**:
- 부위 이름은 아이템 종류와 같은 `hat`·`clothes`·`accessory`다(명세의 `outfit` 대신 `clothes`). `items.avatar_slot` 컬럼 없이 종류가 곧 부위다.
- 블로그 홈 위쪽의 우리 집·프로필 카드·동물 도감은 아직 없다. 지금은 블로그 머리 오른쪽(휴대폰은 위)에 미니룸만 더했다. 우리 집 가구는 다음 단계.
- 입구는 블로그 홈 주인 도구 `🎨 꾸미기`와 상점에서 산 뒤 안내의 `🎨 꾸미기로` 링크다(광장·☰ 메뉴가 없다).
- 캐릭터가 하나뿐이라 `🐾 내 캐릭터` 구역은 없다. 광장 장식 구역도 없다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 배경 걸기 (Priority: P1) 🎯

1. 가입하면 기본 배경 초원을 받아 미니룸에 건다(이미 있는 회원은 마이그레이션이 준다).
2. `/closet` `🖼 내 배경`에서 가진 배경을 누르면 미니룸이 바로 바뀌고 저장된다. 블로그 홈 미니룸에도 보인다.

### User Story 2 - 아바타 입기 (Priority: P1)

1. `👕 아바타 꾸미기`: 가진 모자·옷·소품을 내 캐릭터에 입힌 그림으로 보여 준다. 없으면 `아직 아바타 아이템이 없어요. 상점에서 모자·옷·소품을 사 보세요.`
2. 누르면 바로 입고 `{이름} 장착을 저장했어요 ✓`(2초). 같은 부위는 바뀌고, 입은 것을 다시 누르면 `{이름}을/를 벗었어요 ✓`.
3. 입은 모습이 헤더 캐릭터, 블로그 프로필 동그라미, 미니룸에 똑같이 보인다. 그리는 순서는 캐릭터 → 옷 → 소품 → 모자.
4. 가지고 있지 않은 아이템은 `가지고 있지 않은 아이템이에요`로 막고 화면을 되돌린다. DB 복합 외래 키가 한 번 더 막는다.

### User Story 3 - 가구 보기 (Priority: P3)

가진 가구가 있으면 `🪑 가구` 구역에 보기만 한다. 맨 아래 상점 안내.
