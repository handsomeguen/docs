# Feature Specification: 휴대폰 아래 탭

**Feature Branch**: `040-phone-tabs`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "응 나머지 끝날때까지 쭉 진행해줘" (039 다음 마을 순서)

**다루는 명세 요구사항**: TOWN-11 휴대폰 회원의 아래 탭(🏠 내 블로그 · 📋 마을 소식 · 🏪 상점 · 🔔 알림 · ☰ 메뉴), TOWN-12 휴대폰 ☰ 메뉴 `/town?menu=1`, NF-06 휴대폰은 광장 없이 탭으로 다닌다, 가입 환영 카드의 휴대폰 안내.

**명세와 다른 점**:
- 휴대폰 ☰ 메뉴 화면에는 ✨ 텔레포트(게임이 없다)와 [✕]가 없다. 내 프로필·알림·친구 목록과 바로 가기(글쓰기·마을 소식·상점·출석), 내 정보·관리자·로그아웃이 있다. 친구 목록에도 ✨가 없다.
- 휴대폰 회원의 헤더 막대는 로고·레벨·코인·👤 내 정보·✏️ 글쓰기·로그아웃만 남긴다. 📋 마을 소식·🏪 상점·📮 출석·🔔·[내 블로그]는 탭과 ☰ 메뉴에 있다. 방문자는 탭이 없고 헤더는 그대로.
- 환영 카드의 휴대폰 안내는 농장·낚시터가 아직 없어 `☰ 메뉴에서 출석·내 프로필·친구 목록을 볼 수 있어요`로 썼다.
- 휴대폰 가로(812×375)는 640px 이상이라 PC처럼 마을이 뜬다(NF-06 기준 640px, 038과 같음).

**v1.7.45에서 바뀐 점** (2026-10-18, 광장 개편 "등불 마을", 코드 저장소 handsomeguen/blogville PR #265, 요구사항 1.85 결정 변경):
- 아래 탭 가운데 🏪 상점(`/shop`)이 **🏘 마을**(`/town`)이 됐다. 상점은 휴대폰 광장의 [🏪 상점]으로 간다. `/town`은 🏘 마을, `/town?menu=1`은 ☰ 메뉴가 지금 탭이다.
- 회원이 ☰ 메뉴 없이 `/town`을 열면 내 블로그로 옮기지 않고 **휴대폰 광장**(`PhonePlaza`: 마을 그림·글쓰기·이웃 새 글·오늘 할 일·장소 6곳·내 우체통)을 본다 (User Story 2의 2번이 바뀜).
- 방문자는 그대로 간단 메뉴(`PhoneTown`)이고 탭이 없다. 친구 마을 `/town/{주소}`도 그대로 그 블로그로 옮긴다.
- 환영 카드의 휴대폰 안내는 `화면 아래 탭으로 마을·마을 소식·알림을 오가고, ☰ 메뉴에서 출석·내 프로필·친구 목록을 볼 수 있어요.`
- 스위치 `PHONE_PLAZA`(`src/components/town/phone-plaza.ts`)를 끄면 예전처럼 상점 탭과 내 블로그로 돌아간다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 아래 탭 (Priority: P1) 🎯

1. 639px 이하 회원 화면 맨 아래에 탭 5개(높이 56px 이상). 지금 화면의 탭은 굵은 강조색(`aria-current="page"`). 내 블로그 탭은 내 글 화면에서도 켜진다.
2. 🔔 탭에 안 읽은 알림 수(1~9, `9+`), 화면을 옮길 때마다 새로 받는다(헤더 🔔와 같은 방식).
3. 페이지 아래를 탭 높이만큼 띄워 마지막 줄이 가리지 않는다. 가로 스크롤은 없다.

### User Story 2 - 휴대폰 ☰ 메뉴 (Priority: P1)

1. ☰ 메뉴 탭은 `/town?menu=1`: 마을 대신 펼친 메뉴 화면. 처음 열 때 초점을 빼앗지 않고, 칸을 고르면 그 창 제목으로 초점이 간다. [‹]로 메뉴.
2. 메뉴 없이 `/town`을 열면 지금처럼 내 블로그로 간다. PC의 `/town?menu=1`은 그냥 마을.
