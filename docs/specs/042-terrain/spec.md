# Feature Specification: 높낮이 있는 마을

**Feature Branch**: `042-terrain`

**Created**: 2026-10-12

**Status**: Implemented

**Input**: User description: "응 나머지 끝날때까지 쭉 진행해줘" (041 다음 마을 순서)

**다루는 명세 요구사항**: TOWN-05 2.5D 마을(3/4 탑다운): 높은 단의 남쪽 가장자리 아래 돌벽 앞면, 길이 지나는 곳만 계단(계단에서는 느리게), 먼 하늘·산과 대기 원근.

**명세와 다른 점**:
- 단은 세 개: 북쪽 언덕(2)·가운데(1)·남쪽 들판(0). 전망대 높이 3, 동쪽 내 정원 둔덕(TOWN-20), 한 단 높은 돌광장, 둑 아래 연못은 아직 없다(정원·낚시터 단계에서). 언덕 위에는 `전망대` 의자만 있다.
- 계단은 서쪽·동쪽 길이 두 절벽을 지나는 4곳(명세는 14곳). 북쪽 언덕은 이번에 새로 낸 언덕 길로 서쪽·동쪽 길과 이어진다.
- 발 상자는 건물과 같은 28×16을 쓴다(명세의 18×10 `TERRAIN_FEET`·모서리 미끄러짐 없음). 계단은 길 반폭 + 15px(`STAIR_PAD`)이라 발보다 충분히 넓다.
- 그림자·원근 기울이기는 넣지 않았다(명세와 같음). 북쪽일수록 하늘빛을 섞고 맨 위에 먼 산을 그린다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 언덕과 계단 (Priority: P1) 🎯

1. 마을에 절벽 두 줄(돌벽 앞면 48px)이 보이고, 위 단이 더 밝다. 맨 위는 하늘과 먼 산(걸을 수 없음).
2. 절벽 앞면은 막히고 계단으로만 오르내린다. 계단에서는 조금 느리다.
3. 북쪽 언덕 위 길 끝에 `전망대` 의자가 있다. 모든 입구·집 앞·계단 양끝에 처음 자리에서 걸어서 닿는다.

## Success Criteria *(mandatory)*

- **SC-001**: `tests/unit/town.test.ts`(갈 수 있는지·계단), `tests/e2e/town.spec.ts`(계단 4곳 오르내리기·앞면 막힘)가 통과하고 기존 마을 시험이 그대로 통과한다.
