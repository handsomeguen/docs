# Contract: 화면 주소와 접근 규칙

| 화면 | 주소 | 접근 | 없거나 권한 없으면 |
|---|---|---|---|
| 첫 화면 (로그인·회원가입 탭) | `/` | 방문자 | 로그인했으면 `/@내주소`로 이동 |
| 블로그 홈 | `/@[slug]` (rewrite → `/blog/[slug]`) | 모두 | 404 |
| 블로그 홈 (카테고리) | `/@[slug]?category={대분류ID}` / `?category={ID}&sub={소분류ID}` | 모두 | 이상한 ID는 무시하고 전체 |
| 블로그 홈 (페이지) | `/@[slug]?page={N}` | 모두 | 이상한 값은 1페이지 |
| 가입 직후 | `/@[아이디]?welcome=1` | 주인에게만 환영 카드 | 남이면 카드 없음 |
| 글 상세 | `/@[slug]/[postId]` | 모두 (비공개는 주인만) | 404 |
| 새 글 | `/write` | 회원 | 비로그인 → `/` |
| 글 수정 | `/write/[postId]` | 그 글의 주인 | 비로그인 → `/`, 남의 글·없는 글·이상한 ID → 404 |
| 블로그 관리 | `/settings/blog` | 회원 (내 블로그) | 비로그인 → `/` |
| 내 정보 | `/settings/account` | 회원 | 비로그인 → `/` |
| 인증 라이브러리 | `/api/auth/get-session` (GET) | 모두 | 그 밖의 `/api/auth/*` → 404 |

## 공통 규칙

- slug 비교는 들어온 문자열 그대로 (대문자 주소는 404).
- `postId`, `category`, `sub`, `page`: 숫자만 적힌 1~2147483647 정수만 유효 (`parseId`). `012`, `1e1`, `2.5`, `-1`, `0`, 아주 큰 수는 무효.
- 다른 블로그의 글 ID를 이 블로그 주소에 붙이면 404.
- 404 화면: 🧭 `길을 잃었어요` / `찾는 블로그나 글이 없거나, 비공개 글이에요.` / [처음으로] (로그인했으면 [내 블로그로]).
- 오류 화면: 🚧 `잠깐 문제가 생겼어요` / [다시 시도] [처음으로].
- 탭 제목: 블로그 홈 `{블로그 이름} | Blogville`, 글 상세 `{글 제목} | {블로그 이름}`, 404 `길을 잃었어요 | Blogville`.

## 블로그 홈 구성

- 머리: 블로그 이름, 소개, 주인 닉네임. 주인에게만 [✏️ 새 글 쓰기] [⚙️ 블로그 관리].
- 왼쪽(휴대폰은 위쪽 접는 목록): `전체 (N)` → 대분류 `(N)` → 들여 쓴 소분류 `(N)`. 지금 고른 항목 강조.
- 가운데: 글 카드 8개 (카테고리 배지, 제목, 본문 요약 120자, `YYYY.MM.DD`, 주인에게 `🔒 비공개`) + 페이지 번호.
- 빈 화면: `아직 쓴 글이 없어요.` (카테고리를 골랐으면 `이 카테고리에 글이 없어요.`), 주인에게 [✏️ 첫 글 쓰기].

## 글 상세 구성

- 카테고리 배지(링크) → 제목 → 닉네임 · 작성일(수정했으면 `· 수정됨`) · `🔒 비공개` → 본문 → 주인에게 [수정] [삭제].
- 아래: 같은 블로그로 돌아가는 [목록으로].
